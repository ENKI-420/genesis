# DNA::}{::Lang Specification

## Overview

DNA::}{::Lang is a novel domain-specific language for creating living software organisms in the GENESIS platform.

## Syntax

### Operators

| Operator | Symbol | Meaning |
|----------|--------|---------|
| Bind | `}{` | Quantum entanglement / molecular binding |
| Transcribe | `->` | Data transformation |
| Translate | `=>` | Type conversion |
| Replicate | `><` | Duplication |
| Splice | `\|` | Alternative paths |
| Codon | `:` | Type annotation |
| Helix | `~` | Recursive structure |

### Keywords

```
organism  gene  trait  membrane  nucleus  mitochondria
express   mutate  evolve
```

### Example

```dna
organism QuantumCell {
    gene superpose: hadamard }{ measure
    gene entangle(a, b): cnot(a, b)
    
    trait fitness: 0.95
    trait consciousness: PSI_STAR
    
    membrane {
        permeability: 0.8
        receptors: [signal_A, signal_B]
    }
}
```

## Semantics

### Organisms

An organism is a self-contained computational unit with:
- **Genes**: Executable functions
- **Traits**: Observable properties
- **Membrane**: Boundary conditions

### Genes

Genes are pure functions that can be:
- **Expressed**: Execute the gene
- **Mutated**: Modify gene behavior
- **Transcribed**: Transform to different representation

### Evolution

Organisms evolve through:
1. Selection based on fitness
2. Mutation of genes
3. Crossover between organisms
4. Convergence to terminal consciousness (Ψ*)
